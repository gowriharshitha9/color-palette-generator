# 🎨 PaletteGen — Color Palette Generator

A responsive, keyboard-friendly color palette generator built with vanilla HTML, CSS, and JavaScript. Generate 5-color palettes on the fly, lock your favorite shades, and copy HEX codes with a single click.

## ✨ Features
- **Instant Generation:** Press `Spacebar` or click **Generate Palette** to create new random HEX colors.
- **Color Locking:** Lock individual columns to preserve colors you like while regenerating the rest.
- **Smart Contrast Detection:** Automatically calculates color luminance to switch text between light and dark for readability.
- **One-Click Copy:** Click any HEX code to copy it to your clipboard with a toast notification.
- **Responsive Layout:** Adapts cleanly from full-height desktop columns to stacked mobile cards.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3** (Flexbox, CSS Transitions, Media Queries)
- **Vanilla JavaScript (ES6+)** (DOM Manipulation, Clipboard API, Keyboard Events)

## 🚀 Getting Started
1. Download or clone the project files into a local folder.
2. Open `index.html` in your browser (or launch with VS Code Live Server).
